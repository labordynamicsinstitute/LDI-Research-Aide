# Email Template When a Deposit is Submitted Outside of the AEA Space

Dear author,

We noticed that the deposit associated with you [JOURNAL] article [Manuscript Number](Title) was initially published outside of the AEA space, which requires some additional steps to bring it into compliance. The updated process is as follows:

1. 
   We will initiate a transfer of your deposit into the AEA-designated space. This typically takes 1–2 business days.

2. **(Only include this if it is relevant)**
   Since the deposit is already published (with an embargo), you can modify the **embargo settings**, but not the content of the deposit itself.

3. 
   Once in the AEA space, create **Version 2** of the deposit.  
   - This version should include:
     - A compliant `README`
     - All required code
     - A `CHANGES.txt` file
   - Submit V2 to the AEA for review.
   Upon approval, we will publish it immediately.

**(again, only include if relevant)** 
4. Optional Embargo (V2): 
   - You may apply an embargo to V2 (up to one year from publication).  
   - The current policy allows embargoes through **May [Next Year]**.
   - Once V2 is published, you may create **Version 3**.  
   - V3 should include:
     - All files/code from V2
     - The data you wish to embargo
   - Submit to the AEA and indicate in the Communication Log that the new data should be embargoed.
   - Upon approval, we will publish the version with the embargo applied. The file list will be visible, but downloads will be restricted until the embargo expires.

This process will ensure that your deposit is fully compliant with AEA data and reproducibility standards.

Please let us know if you have questions at any stage. We will notify you as soon as the initial transfer to the AEA space is complete.

Many thanks in advance.
