title: Rejuvenating Hiring Application Form
--- 

1. Find the "LDI Replication Lab Application Form"  on Google Drive.

2. Unlink the form from the [MASTER Replication Project Resumes](https://docs.google.com/spreadsheets/d/1Ic4UgBR3gNFvgyFigJ5SAnx0rZwlp9vu_9OV39YoXQQ/edit?pli=1#gid=1902712667) spreadsheet.
    - Find the linked tab, click Tools and Manage Form. "Unlink form" and "Edit form".

3. Delete all responses.

4. Enable new responses.

5. Edit the Form:
    - Application Deadline: change to two days before training date
    - Adjust the Job Requisition ID

6. Link the form back to the [MASTER Replication Project Resumes](https://docs.google.com/spreadsheets/d/1Ic4UgBR3gNFvgyFigJ5SAnx0rZwlp9vu_9OV39YoXQQ/edit?pli=1#gid=1902712667) spreadsheet. This should create a new tab at the bottom.

7. Rename the tab. Example: "Fall 2024 F" (F for form input) or accordingly

8. Move the tab to the right of the "Live" tab.
