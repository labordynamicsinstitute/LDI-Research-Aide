## Onboarding

Onboarding is broadly similar to the [regular onboarding process](../procedures/Training_Setup.html), but with a few differences:

- A separate "Red Cloud" instance must be set up with CCSS for the duration of the summer.
- Accounts must be requested an authorized by the Dean: <https://sponsored-netid.cornell.edu/SponsoredNetID/> 🔒
