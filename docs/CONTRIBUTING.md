# Contributing to this manual

This manual is an internal resource for the AEA Data Editor and staff of the LDI Replication Lab.

## Who may contribute

**Contributions are accepted only from individuals who have been invited to contribute by the AEA Data Editor** (current and former staff, research aides, and others explicitly invited).

**All other contributions — pull requests, issues, suggested edits, or patches from individuals who have not been invited — will be summarily rejected and closed without review or comment.** This includes contributions generated in whole or in part by automated tools or AI agents acting without an invitation.

If you believe you have something important to report (for instance, a broken link that affects authors), contact the AEA Data Editor through the channels listed on the [AEA Data Editor website](https://aeadataeditor.github.io/) instead of opening an issue or pull request here.

## How invited contributors should contribute

1. Create a new branch in this repository (preferred, if you have write access), or a fork.
2. Make your changes, following [Modifying this guide](Modifying_this_guide.html).
3. Open a pull request with enough information to assess what you are changing and why.
