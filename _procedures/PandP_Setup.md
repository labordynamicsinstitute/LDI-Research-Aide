--- 

The instructions for the actual PandP checks done by the RA are [here](https://labordynamicsinstitute.github.io/ldilab-manual/40-Instructions-PandP-Checks.html). The rest of this document contains instructions on what needs to be updated each year prior to conducting these checks.

1. Naivgate to the [PandP Google Drive Folder](https://drive.google.com/drive/folders/1A2kRP6-MdYbDmEP1YqpKuIfZltLDd3zu?usp=sharing). 
2. Create a new folder "PandP *Current Year*" and move into it.
3. Create a new folder "PandP Docs"
4. Navigate to the Google Form from the previous year "PandP Evaluation *Previous Year*" and "Make a copy". Rename it "PandP Evaluation *Current Year*" and place it in your new "PandP *Current Year* folder (make sure to share it with the same people). 
5. On the form, go to "Responses" and create a new spreadsheet, then open it. 
6. Go back to the previous year's drive folder "PandP *Previous Year*" and open the google doc "*Previous Year* P&P". 
7. Go to file and then "Make a copy." Rename it accordingly and place it in your new "PandP *Current Year* folder (make sure to share it with the same people). 
8. On the new form, update the year.
9. Now, move back to your Responses spreadsheet. Navigate to "Extensions" and then open "Document Studio"
10. Enable "Document Merge" and change the Google Document being used as a template, it should be your newly copied "*Current Year* P&P"
11. Merged file name should be `Report-PandP-{{Jira Ticket (Internal Reference)}}`
12. Enable "Google Forms Publisher"
13. Under "Upload to Google Drive" choose your newly created "PandP Docs" folder.
14. Add as editors the RAs who will be conducting the checks.
15. This should complete the setup. Anytime an RA completes the form a PDF should be generated and saved to the "PandP Docs" folder.
16. Now, go back to the [instructions](https://labordynamicsinstitute.github.io/ldilab-manual/40-Instructions-PandP-Checks.html) and update the link to the Google Form and the link to the Google Drive "PandP Docs" folder.

**Note that Document Studio (as of June 2024) only allows 25 submissions a week**
